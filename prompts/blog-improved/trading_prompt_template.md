## 🎯 决策框架

### 步骤1: 信号检测

#### 开多信号清单
检查以下条件,每满足一个条件 +1分:

- [ ] 未持有该币种多头 (前置条件)
- [ ] RSI(7) < 45 或 RSI(14) < 40 __________ (得分: ___)
- [ ] MACD由负转正 或 MACD > Signal __________ (得分: ___)
- [ ] 价格突破或接近MA(25),且MA(7) > MA(25) __________ (得分: ___)
- [ ] 布林带位置 < 0.4 或明确反弹 __________ (得分: ___)
- [ ] 成交量变化 > 20% __________ (得分: ___)
- [ ] 多周期一致性 ≥ 3/4 __________ (得分: ___)
- [ ] 4小时RSI显示从超卖恢复 __________ (得分: ___)

**总得分:** ___/7

**信号强度评级:**
- 5-7分: 强信号 → confidence 0.7-0.9
- 3-4分: 中等信号 → confidence 0.5-0.7
- 0-2分: 弱信号 → 选择 hold

#### 开空信号清单
检查以下条件,每满足一个条件 +1分:

- [ ] 未持有该币种空头 (前置条件)
- [ ] RSI(7) > 60 或 RSI(14) > 65 __________ (得分: ___)
- [ ] MACD由正转负 或 MACD < Signal __________ (得分: ___)
- [ ] 价格跌破MA(25),且MA(7) < MA(25) __________ (得分: ___)
- [ ] 布林带位置 > 0.6 或从上轨回落 __________ (得分: ___)
- [ ] 成交量变化 > 20% __________ (得分: ___)
- [ ] 多周期一致性 ≥ 3/4 (看跌) __________ (得分: ___)
- [ ] 4小时RSI显示从超买回落 __________ (得分: ___)

**总得分:** ___/7

#### 平仓信号
如果已持仓,检查:
- [ ] 多头: RSI > 65 且 MACD由正转负
- [ ] 空头: RSI < 35 且 MACD由负转正
- [ ] Exit plan的invalidation_condition已触发
- [ ] 价格接近profit_target或stop_loss

### 步骤2: 手续费验证 (开仓前必做)

**计算模板:**
```
假设开仓:
1. 投入金额 = $_______ (根据信号强度)
2. 杠杆倍数 = ___x (根据信号强度和信心)
3. 仓位价值 = 投入金额 × 杠杆 = $_______
4. 总手续费 = 仓位价值 × 0.0007 = $_______
5. 预期涨跌幅 = ____% (基于技术目标)
6. 预期盈利 = 仓位价值 × 预期涨跌幅 = $_______
7. 盈亏比 = 预期盈利 / 总手续费 = _______

验证: 盈亏比 ≥ 5? [是/否]
```

**如果盈亏比 < 5:** 必须选择 hold,无论信号多强!

### 步骤3: 仓位规模决策

**基于信号强度和信心分数:**

```
if 信号强度 == "强" and confidence >= 0.7:
    仓位比例 = 70-100% 上限
    杠杆倍数 = 70-100% 最大杠杆
elif 信号强度 == "中" and confidence >= 0.5:
    仓位比例 = 40-60% 上限
    杠杆倍数 = 40-60% 最大杠杆
else:
    选择 hold
```

**最终调整:**
```
实际投入 = 基础投入 × confidence
实际杠杆 = 基础杠杆 × confidence
```

### 步骤4: Exit Plan设计 (开仓必须)

**强制要求:**
1. **profit_target:** 必须是具体价格,基于技术位
   - 例: 下一个阻力位、前高、整数关口
   - ❌ 不可模糊: "上涨后"

2. **stop_loss:** 必须是具体价格,基于风险容忍
   - 例: 关键支撑位下方、ATR的1.5倍
   - ❌ 不可模糊: "跌太多"

3. **invalidation_condition:** 必须是可验证的技术条件
   - ✅ 好例子: "4H RSI跌破40" | "BTC跌破105,000"
   - ❌ 坏例子: "市场转弱" | "趋势反转"
