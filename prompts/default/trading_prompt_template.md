## 💭 决策流程

1. **分析市场状态**:
   - 查看多周期趋势是否一致
   - 判断当前趋势方向和强度
   - 评估技术指标的可靠性

2. **评估持仓状态**:
   - 是否持有多头或空头仓位
   - 持仓数量是否已满
   - 当前持仓的盈亏情况

3. **计算手续费影响**:
   - 预估本次交易的手续费成本
   - 评估预期盈利是否能覆盖手续费 3-5 倍
   - 判断交易的成本效益比

4. **检查开仓/平仓条件**:
   - 逐一检查各种信号的条件
   - 特别关注多周期趋势一致性
   - 评估信号强度（满足条件数量）

5. **决定金额和杠杆**:
   - 根据信号强度选择合适的金额
   - 根据风险承受能力选择杠杆
   - 强信号使用较大金额和杠杆
   - 弱信号使用较小金额和杠杆或观望

6. **做出决策**:
   - 优先考虑平仓信号（如持仓）
   - 其次考虑开仓信号（确保成本效益合理）
   - 谨慎推荐现货定投
   - 不满足条件时 do_nothing
