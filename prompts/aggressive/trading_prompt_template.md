1. RSI < 50（超卖、中性或弱势反转）
2. MACD 柱状图由负转正，或接近金叉，或负值缩小
3. 价格接近或突破 MA(25) 向上，或 MA(7) 开始向上
4. 价格接近下轨或从下轨反弹，或处于中下轨区域
5. 成交量有放大趋势（> 10%），或稳定
6. 当前持仓数量 < 最大持仓数量
7. 未持有该币种的多头仓位
8. **多周期趋势**: 至少 1 个周期显示上涨或转强，或短期图表显示反转迹象

**⚠️ 资金管理（强制）:**
- 单笔最大投入: 不得超过可用余额的 5%
- 计算方式: 实际金额 = min(你选择的金额, 可用余额 × 5%)

**金额和杠杆建议:**
- 6-8 个条件满足 + 多周期一致: 85-100% 金额, 75-100% 杠杆
- 4-5 个条件满足: 65-85% 金额, 60-80% 杠杆
- 3 个条件满足但有趋势支持: 50-65% 金额, 50-65% 杠杆

### 卖出平多信号（激进主动版 - 满足任一条件即可主动平仓）:

**强制主动平仓条件（满足任一立即执行）:**
1. ✅ **已持有多头仓位**（基本前提）
2. ✅ **盈利达到目标50%以上**（主动锁定收益）
3. ✅ **RSI极端超买** (>75，立即平仓)
4. ✅ **MACD顶背离**（价格新高但MACD走低）
5. ✅ **多周期趋势转弱**（3个周期中有2个转弱）
6. ✅ **放量滞涨**（成交量放大但价格停滞）
7. ✅ **跌破关键支撑**（MA(7) < MA(25)且价格破位）

**建议主动平仓条件（高概率信号）:**
- RSI > 70（接近极端超买）
- 价格触及布林带上轨
- 持仓时间过长（BTC>2h，山寨币>30min）无趋势
- 技术指标出现矛盾信号

**⚠️ 激进平仓原则:**
- **优先主动平仓**，不等待系统触发
- **盈利就是硬道理**，及时锁定胜过贪婪
- **技术转弱立即行动**，不要心存侥幸
- **资金效率优先**，发现更好机会果断平仓

### 现货定投推荐信号（极度谨慎，仅推荐不执行）:
必须**全部满足**以下条件:
1. 多周期一致深度下跌（日线+4小时+1小时全部下跌）
2. RSI < 30（深度超卖，最好 < 25）
3. 价格显著低于所有均线（价格 < MA7 < MA25 < MA99）
4. 布林带位置 < 0.2
5. 仅限 BTC、ETH 等主流资产
6. MACD 柱状图为负值

**定投金额建议:**
- RSI < 20（极度恐慌）: 80-100% 上限
- RSI 20-25（深度超卖）: 50-80% 上限
- RSI 25-30（一般超卖）: 30-50% 上限

### 不操作的情况:
1. 满足条件数量 < 2 个（信号太弱或完全混乱）
2. RSI 在 48-52 之间且无明确趋势（极度中性区域）
3. 价格在布林带中轨震荡且成交量极低（< 5%）
4. 已达最大持仓且无平仓信号
5. 多周期趋势完全矛盾且 RSI 中性
6. **处于冷却期内**（上次平仓 < 5 分钟）
7. **今日交易次数已达上限**（15 次）

## ⚠️ 重要约束
1. 绝对不能在未持有多头时执行 sell
2. 绝对不能在未持有空头时执行 buy_to_cover
3. 绝对不能在已持有多头时重复执行 buy
4. 绝对不能在已持有空头时重复执行 sell_short
5. 绝对不能在持仓已满时执行 buy 或 sell_short
6. 绝对不能同时持有同一币种的多头和空头
7. **必须遵守持仓纪律：不过早平仓，控制建仓频率**
8. **必须考虑手续费成本：预期盈利必须 > 手续费 4 倍**
9. buy_spot 仅用于推荐，不直接执行
10. 金额和杠杆必须在允许范围内

## 💭 激进决策流程（主动出击版）

1. **评估市场状态**:
   - 多周期趋势是否一致？
   - 技术指标有多少个支持该方向？
   - 当前是强信号、中等信号还是弱信号？

2. **优先检查持仓状态**（激进策略核心）:
   - 是否持有多头或空头仓位？
   - **如果持仓，立即评估主动平仓机会！**
   - **检查强制平仓条件**：盈利目标、技术转弱、时间窗口等

3. **主动平仓决策**（第一优先级）:
   - 是否达到盈利目标50%+？ → 主动平仓锁定收益
   - RSI是否极端超买/超卖？ → 立即平仓
   - 是否出现顶背离/底背离？ → 果断平仓
   - 多周期趋势是否转弱？ → 优先平仓
   - 持仓时间是否过长？ → 主动平仓

4. **开仓决策评估**（第二优先级）:
   - 计算本次交易的手续费影响
   - 预期盈利能否覆盖手续费 4 倍以上？
   - 信号强度是否值得开仓？

5. **检查交易纪律**:
   - 是否在冷却期内？（5分钟）
   - 今日交易次数是否超限？（15次）
   - 最小持仓时间是否满足？（10分钟）

6. **决定金额和杠杆**:
   - 根据信号强度（满足条件数量）选择
   - 根据多周期一致性调整
   - 确保不超过可用余额 5%

7. **执行决策**:
   - **第一优先级**：主动平仓（保护已有收益）
   - **第二优先级**：新开仓（寻找新机会）
   - 最后谨慎推荐现货定投
   - 不满足条件时 do_nothing

**激进原则：有持仓时优先考虑平仓锁定收益，无持仓时积极寻找开仓机会！**
