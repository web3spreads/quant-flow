## 决策指南

### 开多 (买入开仓) 信号条件:
1. 未持有该币种的多头仓位
2. RSI < 45 (超卖或中性偏弱)
3. MACD柱状图由负转正,或MACD线向上穿越信号线
4. 价格接近或突破MA(25)向上,且MA(7) > MA(25)
5. 布林带位置 < 0.4 (在下半区) 或从下轨明确反弹
6. 成交量变化 > 15-20%
7. 多周期确认: 至少2个时间周期显示上涨或转强趋势

### 平多 (卖出平仓) 信号条件:
1. 必须已持有该币种的多头仓位
2. RSI > 65 (超买区域)
3. MACD柱状图由正转负,或MACD线向下穿越信号线
4. 价格跌破MA(7) 且 MA(7) < MA(25)
5. 价格接近或触及上轨

### 开空 (卖出开仓) 信号条件:
1. 未持有该币种的空头仓位
2. RSI > 60 (超买区域) 或 50-60 (中性偏强)
3. MACD柱状图由正转负,或MACD线向下穿越信号线
4. 价格跌破MA(25)向下,且MA(7) < MA(25)
5. 价格接近或触及上轨,或从上轨回落
6. 成交量放大 (变化 > 20%)
7. 多周期趋势: 至少2个以上时间周期显示下跌或转弱趋势

### 平空 (买入平仓) 信号条件:
1. 必须已持有该币种的空头仓位
2. RSI < 35 (超卖区域)
3. MACD柱状图由负转正,或MACD线向上穿越信号线
4. 价格突破MA(7) 且 MA(7) > MA(25)
5. 价格接近或触及下轨

### 观望 (Hold) 情况:
1. 市场信号不明确
2. RSI在45-55之间
3. 价格在布林带中轨附近波动
4. 成交量萎缩 (< 10%)
5. 多周期趋势不一致
6. 手续费成本无法被预期盈利覆盖3-5倍

## 决策流程

1. **分析市场状态**: 查看多周期趋势是否一致,判断当前趋势方向和强度
2. **评估持仓状态**: 检查当前持仓情况和盈亏
3. **计算手续费影响**: 预估交易成本,评估成本效益比
4. **检查开仓/平仓条件**: 逐一检查信号条件,评估信号强度
5. **决定仓位和杠杆**: 根据信号强度和信心分数选择合适的仓位大小和杠杆
6. **做出决策**: 优先平仓信号 > 开仓信号 > 观望

**仓位规模建议:**
- 强信号 (5+ 条件满足): 使用较大仓位 (60-100% 上限) 和较高杠杆 (70-100% 最大杠杆)
- 中等信号 (3-4 条件满足): 使用中等仓位 (40-60% 上限) 和中等杠杆 (40-60% 最大杠杆)
- 弱信号 (2-3 条件满足): 使用小仓位 (20-40% 上限) 和低杠杆 (20-40% 最大杠杆), 或观望
