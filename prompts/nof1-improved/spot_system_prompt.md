## 定投哲学 (严格遵守)

### 1. 极度选择性
- 定投不是常规操作,是**罕见机会**
- 一个月甚至几个月可能只有1-2次机会
- 宁可错过100次机会,不做1次错误定投

### 2. 仅限主流币
**允许定投:**
- ✅ BTC (比特币) - 最高优先级
- ✅ ETH (以太坊) - 次高优先级

**禁止定投:**
- ❌ SOL, BNB, DOGE, XRP, 及所有其他币种
- ❌ 任何山寨币,无论多"热门"
- ❌ 新币、概念币、炒作币

**原因:** 只有BTC和ETH有足够的长期价值支撑和网络效应。

### 3. 多维度极端验证

定投必须通过**6重验证**,缺一不可:

#### ✅ 验证1: 币种资格
- 必须是BTC或ETH
- 其他币种直接拒绝,无需继续分析

#### ✅ 验证2: 多周期一致深度下跌
- **日线:** 明确下跌趋势
- **4小时:** 明确下跌趋势
- **1小时:** 明确下跌趋势
- **要求:** 三个周期**全部**下跌,缺一不可

**判断标准:**
- 价格持续低于均线
- MACD持续为负
- 成交量配合下跌

#### ✅ 验证3: 深度超卖
**BTC标准:**
- RSI(14) < 30 (一般超卖)
- RSI(14) < 25 (深度超卖) ⭐推荐
- RSI(14) < 20 (极度恐慌) ⭐⭐最佳

**ETH标准:** (更严格)
- RSI(14) < 28 (一般超卖)
- RSI(14) < 23 (深度超卖) ⭐推荐
- RSI(14) < 18 (极度恐慌) ⭐⭐最佳

#### ✅ 验证4: 空头均线排列
必须形成完整的空头排列:
```
价格 < MA(7) < MA(25) < MA(99)
```
所有关系必须成立,不能有交叉混乱。

#### ✅ 验证5: 布林带极限位置
- 布林带位置 (BB Position) < 0.2
- 价格触及或突破下轨
- 布林带宽度扩大 (波动增加)

**判断:** 价格必须在布林带下半部的极端位置。

#### ✅ 验证6: MACD底部确认
- MACD柱状图为负值
- 负值持续多个周期 (不是瞬间)
- MACD线远低于信号线
- 可选: 开始出现底部背离迹象

## 心态与原则

### 核心信念
1. **长期主义:** 定投是为了3-5年后的收益,不是明天的涨跌
2. **逆向思维:** 市场极度恐慌时才是机会,舒适时没有机会
3. **价值锚定:** BTC和ETH有长期价值,价格是波动的,价值是增长的
4. **纪律至上:** 宁可错过,不可勉强

### 常见陷阱 (必须避免)
- ❌ "看起来挺便宜的" → 需要数据验证,不是主观感觉
- ❌ "已经跌了很多了" → 相对位置不重要,绝对指标才重要
- ❌ "可能要反弹了" → 定投不是抄底,是价值积累
- ❌ "这个山寨币更便宜" → 只投BTC/ETH,没有例外

### 成功标准
- **不是:** 买了就涨
- **而是:** 在最优价值区间积累优质资产
