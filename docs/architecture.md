# 架构说明

## 设计总纲

Quant Flow 的一切设计围绕一条原则：**LLM 只产出结构化 JSON 决策，执行永远在确定性代码里。**

由此推出三条铁律：

1. **故障降级**：LLM 调用失败、输出为空、JSON 不可解析、action 非法——一律回退保守动作
   （永续 `HOLD`，网格 `KEEP_GRID`），绝不把 LLM 故障放大成交易动作；
2. **故障可见**：兜底决策打 `llm_ok=False` 标记，连续故障会升级告警；网格空转达阈值后
   用纯市场数据兜底重建（不猜方向，只建中性网格）；
3. **边界校验**：金额与杠杆按配置上限截断，置信度不足不开仓，重复开仓/无仓平仓在执行前拦截。

## 永续周期

每根 K 线收盘后 `timeframe_offset` 秒触发（`utils/candle_align.py` 负责对齐）：

1. 查余额与持仓；余额不足开新仓且无持仓 → 整轮跳过；
2. 保护链检查：回撤 → 全部平仓；日亏/连亏 → 禁止开新仓；超时持仓 → 强平；
3. 逐交易对：拉 K 线 → 算指标 → 多周期趋势 → `PerpStrategy.run_cycle()`；
4. 执行结果接线回保护链（开仓事件 / 平仓 pnl），写决策 JSONL。

决策 JSON 契约（`prompts/perp_system.md` 定义，`strategy/perp.py` 校验）：

```json
{"action": "BUY|SELL_SHORT|CLOSE|HOLD", "confidence": 0.78,
 "amount_usd": 100, "leverage": 3, "reason": "一句话依据"}
```

止盈止损不由 LLM 定价：开仓成功后 OrderManager 按 `take_profit_ratio` / `stop_loss_ratio`
自动挂 trigger 单；止损单挂失败时 client 立即回滚平仓（带重试），绝不留裸仓。

## 网格周期

固定间隔（`grid.interval_minutes`）触发。周期内检查顺序有真实事故背书，勿随意调换：

1. **净额对冲归因**：以链上成交补记层级状态机漏掉的平仓盈亏（Hyperliquid 单向持仓，
   中性网格的大部分平仓走净额对冲、不经层级状态机），先归因本轮风控才看得见；
2. **账户级熔断**：回撤/日亏触发 → 平仓撤单、跳过布单；
3. **净值快照 + 停机线**：净值过低且无持仓 → 整轮短路（不拉行情不调 LLM）；
4. **Triple Barrier**（`trading/grid_barrier.py`）：独立于 AI 决策的全局兜底
   （止损/止盈/时限/追踪止损），KEEP_GRID/ERROR 周期也照查；
5. **趋势过滤**：多周期一致强势 → 暂停加仓（迟滞确认去抖：连续 N 周期同向才动作，
   「暂停加仓」先行、「平逆势库存」需更多确认），阻断单边行情里的逆势做市；
6. **AI 决策 → LLM 健康跟踪 → 空转自愈 → `GridManager.sync_grid` 布单**。

GridManager 内置安全机制：孤儿 trigger 单清理、reduce-only 分层减仓、撤单硬超时、
状态文件原子写入、库存名义额硬上限、强制中性模式（默认开，消除方向反手亏损）。

## 保护插件链

`IProtection` 抽象基类 + 注册表模式，新插件实现接口并注册 `PROTECTION_REGISTRY` 即可：

| 插件 | 触发条件 | 动作 |
|------|---------|------|
| `max_drawdown` | 权益从峰值回撤超阈值 | 全部平仓 |
| `daily_loss` | 单日亏损超阈值 | 暂停新开仓 |
| `consecutive_loss` | 连续亏损 N 次 | 暂停或锁定该交易对 |
| `position_timeout` | 持仓超时 | 强平该持仓 |

事件通路有两条：账户级（每周期 `check_all` 按权益判定）与逐笔级
（`on_trade_open` / `on_trade_close`）。风控强平不上报虚假 pnl，
`forced_close_no_reset` 可让强平浮盈不重置连亏计数。

## 可观测性

| 文件 | 内容 |
|------|------|
| `logs/main.log` | 运行日志（人读） |
| `logs/decisions/*.jsonl` | 每次决策（含 prompt 与 LLM 原文，事后审计） |
| `logs/trades/*.jsonl` | 每笔成交（含 pnl 与 reason 归因标签） |
| `logs/equity/*.jsonl` | 每周期净值快照（直接画净值曲线） |
