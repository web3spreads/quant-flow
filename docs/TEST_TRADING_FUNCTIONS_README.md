# 交易功能测试脚本使用指南

## 📖 概述

`test_trading_functions.py` 是一个交互式的交易功能测试脚本，用于在配置好 API 密钥后测试 Bitget 交易功能。

## ✨ 功能特性

1. **📊 查询账户信息**
   - 查询 USDT 余额
   - 查询详细余额信息（总余额、占用资金、可用余额）
   - 查询当前持仓（多头和空头）

2. **📈 测试买入 (开多)**
   - 检查余额是否足够
   - 显示买入详情（价格、数量、止盈止损）
   - 执行买入操作

3. **📉 测试卖出 (平多)**
   - 检查是否持有多头仓位
   - 执行卖出平仓操作

4. **📉 测试做空 (开空)**
   - 检查余额是否足够
   - 显示做空详情（价格、数量、止盈止损）
   - 执行做空操作（现货模式为模拟做空）

5. **📈 测试平空 (平空)**
   - 检查是否持有空头仓位
   - 执行买入平空操作

6. **🔄 运行完整测试流程**
   - 自动按顺序执行所有测试
   - 每个步骤都有确认提示

## 🚀 快速开始

### 1. 配置 API 密钥

在 `config.yaml` 中配置你的 Bitget API 密钥：

```yaml
# Bitget API 配置（模拟盘）
bitget_api_key: "your_api_key_here"
bitget_api_secret: "your_api_secret_here"
bitget_passphrase: "your_passphrase_here"

# 运行模式
demo_trading: true  # 使用模拟盘
test_mode: false    # 不使用本地测试模式
```

### 2. 运行测试脚本

```bash
# 方式 1: 使用 uv 运行
uv run python test_trading_functions.py

# 方式 2: 直接运行
python test_trading_functions.py

# 方式 3: 作为可执行文件
./test_trading_functions.py
```

### 3. 选择测试功能

运行后会看到交互式菜单：

```
═══════════════════════════════════════════════
请选择要测试的功能:

  1 - 📊 查询账户信息
  2 - 📈 测试买入 (开多)
  3 - 📉 测试卖出 (平多)
  4 - 📉 测试做空 (开空)
  5 - 📈 测试平空 (平空)
  6 - 🔄 运行完整测试流程
  0 - 🚪 退出

请输入选项:
```

## ⚠️ 注意事项

### 1. 模拟盘 vs 真实交易

**强烈建议先在模拟盘测试！**

**模拟盘模式**（推荐）：
```yaml
demo_trading: true
test_mode: false
```

**真实交易模式**（谨慎！）：
```yaml
demo_trading: false
test_mode: false
```

### 2. API 密钥配置

- **模拟盘**: 使用模拟盘的 API 密钥
- **真实交易**: 使用真实账户的 API 密钥（谨慎！）

获取 API 密钥：
1. 登录 Bitget 官网
2. 进入 API 管理页面
3. 创建 API Key（选择"模拟盘"或"现货账户"）
4. 将 Key、Secret、Passphrase 填入 config.yaml

### 3. 交易金额建议

- **测试阶段**: 使用小金额（10-50 USDT）
- **真实环境**: 根据实际情况调整

### 4. 做空功能

- **现货模式**: 做空为模拟操作，仅记录持仓信息
- **合约模式**: 做空为真实操作（需要合约账户）

## 🔧 故障排除

### 问题 1: 无法连接 API

**症状**：
```
❌ 初始化失败: API connection error
```

**解决方案**：
1. 检查网络连接
2. 确认 API 密钥是否正确
3. 确认是否选择了正确的环境（模拟盘/真实交易）

### 问题 2: 余额为 0

**症状**：
```
USDT 余额: 0.00
```

**解决方案**：
1. 模拟盘需要先在 Bitget 网站上充值虚拟资金
2. 确认 API 密钥对应的账户类型正确

### 问题 3: 买入/卖出失败

**症状**：
```
❌ 买入失败
```

**解决方案**：
1. 检查余额是否足够
2. 检查交易对格式是否正确（如 BTC/USDT）
3. 检查 API 权限是否包含交易权限

### 问题 4: 找不到持仓

**症状**：
```
⚠️  未持有 BTC/USDT 的多头仓位，无法卖出
```

**解决方案**：
1. 先执行买入操作
2. 确认交易对名称正确
3. 检查是否在查询正确的持仓方向（多头/空头）

## 💡 使用技巧

### 1. 逐步测试

建议按以下顺序测试：
1. 先测试账户信息查询（选项 1）
2. 再测试买入功能（选项 2）
3. 然后测试卖出功能（选项 3）
4. 最后测试做空相关功能（选项 4、5）

### 2. 使用小金额

初次测试时使用小金额（如 10-20 USDT），确认功能正常后再增加金额。

### 3. 记录测试结果

可以将测试输出保存到文件：
```bash
uv run python test_trading_functions.py 2>&1 | tee test_results.log
```
