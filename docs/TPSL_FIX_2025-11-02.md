# 止盈止损功能修复 - 2025-11-02

## 🎯 修复的问题

根据用户反馈，修复了两个关键问题：

### 1️⃣ 精度查询失败（404错误）

**问题描述**:
```
获取 BTC/USDT 精度信息失败: API Request Error(code=40404): 请求的URL不存在
```

**根本原因**:
- SDK 使用的 API 路径 `/api/v2/spot/market/symbols` 不存在（需要私有认证）
- 正确的公开 API 路径是 `/api/v2/spot/public/symbols`（无需认证）
- 字段名称错误：
  - ❌ 错误: `quantityScale`, `priceScale`
  - ✅ 正确: `quantityPrecision`, `pricePrecision`

**修复方案**:
不再依赖 SDK 的 `MarketApi`，直接使用 `requests` 调用公开 API：

```python
import requests

url = 'https://api.bitget.com/api/v2/spot/public/symbols'
params = {'symbol': 'BTCUSDT'}

response = requests.get(url, params=params, timeout=10)
data = response.json()

if data.get('code') == '00000' and data.get('data'):
    symbol_info = data['data'][0]
    precision = {
        'quantity_precision': int(symbol_info.get('quantityPrecision', 6)),
        'price_precision': int(symbol_info.get('pricePrecision', 2))
    }
```

**参考文档**: https://www.bitget.com/zh-CN/api-doc/spot/market/Get-Symbols

### 2️⃣ 止盈设置不生效

**问题描述**:
用户反馈：止损成功设置，但止盈没有设置成功。

**根本原因**:
参数名错误！
- ❌ 错误参数: `presetStopSurplusPrice`（此参数不存在于 Bitget API）
- ✅ 正确参数: `presetTakeProfitPrice`

**修复代码**:
```python
# 修复前
if take_profit_price and side == 'buy':
    params["presetStopSurplusPrice"] = tp_price  # ❌ 错误

# 修复后
if take_profit_price and side == 'buy':
    params["presetTakeProfitPrice"] = tp_price  # ✅ 正确
```

**Bitget API 正确参数**:
- `presetTakeProfitPrice` - 止盈价格 ✅
- `presetStopLossPrice` - 止损价格 ✅

**参考文档**: https://www.bitget.com/zh-CN/api-doc/spot/trade/Place-Order

## 🚀 功能增强：卖出操作动态精度

### 问题背景
用户反馈：卖出动作也需要查询小数位数并应用动态精度。

### 优化内容

#### 1. `place_market_order` - 市价单
**优化前**: 直接使用传入的数量，没有精度舍入
```python
params = {
    "symbol": symbol,
    "side": side,
    "size": amount  # 直接使用，可能精度不匹配
}
```

**优化后**: 卖出时自动应用动态精度
```python
# 获取动态精度
precision = self.get_symbol_precision(symbol)
quantity_precision = precision['quantity_precision']

# 卖出时应用精度
if side == 'sell':
    order_size = str(round(float(amount), quantity_precision))
    print(f"✅ 卖出数量应用精度 {quantity_precision}: {amount} -> {order_size}")
```

#### 2. `place_plan_order` - 计划单
**优化前**: 数量和触发价都没有精度舍入

**优化后**: 数量和触发价都应用动态精度
```python
# 获取动态精度
precision = self.get_symbol_precision(symbol)
quantity_precision = precision['quantity_precision']
price_precision = precision['price_precision']

# 应用精度舍入
rounded_amount = str(round(float(amount), quantity_precision))
rounded_trigger_price = str(round(float(trigger_price), price_precision))

print(f"✅ 计划单应用精度 数量={quantity_precision}, 价格={price_precision}")
```

#### 3. `place_order_with_tpsl` - 带止盈止损的订单
**优化前**: 止盈止损仅支持买入订单（`side == 'buy'`）

**优化后**: 买入和卖出都支持止盈止损
```python
# 移除了 side == 'buy' 的限制
if take_profit_price:
    tp_price = str(round(float(take_profit_price), price_precision))
    params["presetTakeProfitPrice"] = tp_price

if stop_loss_price:
    sl_price = str(round(float(stop_loss_price), price_precision))
    params["presetStopLossPrice"] = sl_price
```
