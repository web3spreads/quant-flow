# 做空功能实现总结

## 🎯 功能概述

为 Quant Flow 交易机器人添加了完整的做空（Short Selling）功能，使系统能够同时支持做多和做空两种交易策略。

## ✅ 实现的功能

### 1. 订单管理器扩展

**文件**: `src/trading/order_manager.py`

新增功能：

#### 空头持仓跟踪
```python
# 跟踪模拟空头持仓（用于现货账户模拟做空）
self.simulated_short_positions: Dict[str, Dict[str, Any]] = {}
```

#### 四个核心方法

1. **execute_sell_short_with_protection()** - 卖空开空
   - 计算做空数量
   - 设置止盈价（价格下跌 5%）
   - 设置止损价（价格上涨 2%）
   - 创建模拟空头持仓记录

2. **execute_buy_to_cover()** - 买入平空
   - 检查空头持仓
   - 创建平仓记录
   - 移除空头持仓

3. **get_current_positions()** - 获取所有持仓
   - 返回多头持仓（实际持仓）
   - 返回空头持仓（模拟持仓）
   - 每个持仓都标记 `side` 字段：'long' 或 'short'

### 2. 交易工具扩展

**文件**: `src/agent/tools.py`

从 3 个工具扩展到 5 个工具：

#### 做多工具
1. **buy** - 买入开多
   - 开设多头仓位
   - 止盈：价格上涨 5%
   - 止损：价格下跌 2%

2. **sell** - 卖出平多
   - 平掉多头仓位

#### 做空工具（新增）
3. **sell_short** - 卖空开空
   - 开设空头仓位
   - 止盈：价格下跌 5%
   - 止损：价格上涨 2%

4. **buy_to_cover** - 买入平空
   - 平掉空头仓位

#### 观望工具
5. **do_nothing** - 不操作

### 3. AI 提示词更新

**文件**: `src/agent/prompts.py`

在批量交易提示词中添加了详细的做空决策准则：

#### 卖空开空信号条件
1. RSI > 60（超买区域）或 50-60（中性偏强）
2. MACD 柱状图由正转负，或 MACD 线向下穿越信号线
3. 价格跌破 MA(25) 向下，且 MA(7) < MA(25)
4. 价格接近或触及布林带上轨，或从上轨回落
5. 成交量放大（变化 > 20%）
6. 当前持仓数量 < 最大持仓数量
7. 未持有该币种的空头仓位
8. 至少 2 个以上时间周期显示下跌或转弱趋势

#### 买入平空信号条件
1. 必须已持有该币种的空头仓位
2. RSI < 35（超卖区域）
3. MACD 柱状图由负转正，或 MACD 线向上穿越信号线
4. 价格突破 MA(7) 且 MA(7) > MA(25)
5. 价格接近或触及布林带下轨

#### 重要约束
- 绝对不能在未持有空头仓位的情况下执行 buy_to_cover
- 绝对不能在已持有空头仓位的情况下重复执行 sell_short
- 绝对不能同时持有同一币种的多头和空头仓位

### 4. TradingAgent 扩展

**文件**: `src/agent/trading_agent.py`

#### 回调函数扩展

新增两个回调：

1. **sell_short_callback()** - 卖空开空回调
   - 检查余额
   - 检查是否已有空头仓位
   - 检查是否已有多头仓位（避免对冲）
   - 执行卖空操作

2. **buy_to_cover_callback()** - 买入平空回调
   - 检查空头持仓
   - 执行平空操作

#### 决策解析扩展

更新了两个解析方法以支持新的决策类型：

1. **_parse_decision_from_events()** - 单个决策解析
   - 添加 "SELL_SHORT" 决策类型识别
   - 添加 "BUY_TO_COVER" 决策类型识别

2. **_parse_batch_decisions_from_events()** - 批量决策解析
   - 支持解析 sell_short 工具调用
   - 支持解析 buy_to_cover 工具调用

## 🔍 实现细节

### 现货账户模式 vs 合约账户模式

#### 现货账户（当前实现）
- 使用 **模拟做空**
- 空头持仓存储在 `simulated_short_positions` 字典中
- 不会实际在交易所开设空头仓位
- 适合测试和回测

#### 合约账户（未来扩展）
- 可以实际开设空头仓位
- 使用交易所的合约/杠杆功能
- 需要修改 `BitgetClient` 支持合约交易

### 止盈止损逻辑

| 操作类型 | 止盈方向 | 止盈价格 | 止损方向 | 止损价格 |
|---------|---------|---------|---------|---------|
| 买入开多 | 价格上涨 | 入场价 × 1.05 | 价格下跌 | 入场价 × 0.98 |
| 卖空开空 | 价格下跌 | 入场价 × 0.95 | 价格上涨 | 入场价 × 1.02 |

### 持仓状态管理

每个持仓包含以下字段：

```python
{
    'symbol': 'BTC/USDT',
    'amount': 0.001667,
    'side': 'long' | 'short',  # 多头或空头
    'entry_price': 60000.0,
    'simulated': True | False  # 是否为模拟持仓
}
```

## 🚀 使用示例

### AI 决策示例

当市场出现看跌信号时，AI 会这样分析：

```
分析 BTC/USDT:
- RSI: 68（超买区域）
- MACD 柱状图由正转负
- 价格接近布林带上轨
- 日线、4小时、1小时均显示下跌趋势
- 多周期趋势一致性高

决策：执行 sell_short 工具
原因：多个时间周期显示明确的看跌信号
```

### 交易流程

#### 做空流程
1. AI 检测到看跌信号
2. 调用 `sell_short` 工具
3. OrderManager 创建模拟空头持仓
4. 设置止盈止损价格
5. 等待平仓信号

#### 平空流程
1. AI 检测到平仓信号（价格反弹或止盈/止损触发）
2. 调用 `buy_to_cover` 工具
3. OrderManager 移除空头持仓
4. 记录交易结果

## ⚠️ 注意事项

1. **模拟模式**：当前实现为模拟做空，不会在交易所实际开设空头仓位
2. **对冲保护**：系统会阻止同时持有同一币种的多头和空头仓位
3. **持仓限制**：做空操作也会计入最大持仓数量限制
4. **风险管理**：做空风险理论上无限，系统会严格执行止损
