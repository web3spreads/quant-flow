# 计划单精度更新

## 🔧 2025-01-14 精度调整

### 问题描述

在测试小额交易时（如 20 USDT 买入 BTC），发现止盈止损计划单创建失败：

**错误信息**:
```json
{"code":"43011","msg":"参数不合符规范 size <= 0"}
```

**问题根源**:
- 买入数量：`0.000182` BTC（20 USDT / 109996.29 价格）
- 原精度设置：`round(0.000182, 3)` = `0.0` ❌
- 结果：计划单数量为 0，API 拒绝

### 修复方案

**文件**: `src/trading/bitget_official_client.py`

**修改位置**:
- 第273行：止盈单数量精度
- 第291行：止损单数量精度

**修改前**:
```python
# 止盈单
plan_amount = str(round(float(amount), 3))  # 3位小数

# 止损单
plan_amount = str(round(float(amount), 3))  # 3位小数
```

**修改后**:
```python
# 止盈单
plan_amount = str(round(float(amount), 6))  # 6位小数 ✅

# 止损单
plan_amount = str(round(float(amount), 6))  # 6位小数 ✅
```

### 技术说明

**为什么从 3 位改为 6 位？**

1. **市价单精度要求**: 最多 8 位小数
2. **计划单精度要求**: 需要合理精度，不能为 0
3. **小额交易场景**:
   - 20-50 USDT 买入 BTC，数量通常在 0.0001-0.0005 范围
   - 需要至少 4-5 位小数才不会舍入为 0
4. **平衡考虑**:
   - 太少（3位）：小额交易被舍入为 0 ❌
   - 适中（6位）：覆盖大多数场景 ✅
   - 最多（8位）：等于市价单精度，是上限 ⚠️

**选择 6 位的原因**:
- 覆盖小额交易（0.000182 → 保留）
- 低于市价单上限（8位）
- 避免精度过高导致其他问题
- 符合 Bitget 计划单的实际精度要求
