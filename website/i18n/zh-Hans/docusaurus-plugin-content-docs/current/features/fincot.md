# FinCoT 结构化推理

**论文依据**：[arXiv:2506.16123](https://arxiv.org/abs/2506.16123) — 准确率 +17.3pp，token 消耗 -8.9x

FinCoT 将 Prompt 决策框架从「条件罗列」改为「6步强制推理链」，迫使 LLM 按固定步骤分析，消除跳跃式推理。

## 6 步推理链

```
步骤1 趋势确认   → 多周期趋势是否一致？
步骤2 入场信号   → 哪些指标触发？（列出具体数值）
步骤3 情绪校验   → 资金费率/恐惧贪婪是否有逆向信号？
步骤4 复盘比对   → 当前情况匹配哪条历史经验？
步骤5 风险计算   → 止损/止盈距离、盈亏比、手续费覆盖率
步骤6 最终决策   → 综合以上 5 步，给出决策和置信度
```

## 启用方式

切换到集成 FinCoT 的 Prompt 集即可启用，无需额外配置：

```yaml
prompt:
  set: nof1-improved   # 推荐
```

所有 8 套 Prompt 模板均已集成 FinCoT。

## Prompt 策略对比

| 策略集 | 风格 | 盈亏比要求 |
|--------|------|-----------|
| `default` | 标准均衡 | 1.5 |
| `conservative` | 趋势分歧即 HOLD | ≥ 2.0 |
| `aggressive` | 3 条件即可入场 | ≥ 1.2 |
| `nof1-improved` | 完整 FinCoT + 增强数据 | 自适应 |
| `realtime` | 价格行为优先 | 1.5 |
